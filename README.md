# 📸 Telegram Media Saver Bot

A Telegram self-bot that saves media (photos, videos, voice messages, GIFs, stickers, documents, and text) to your Saved Messages when you reply with a save command.

## ✨ Features

- 📷 Save Photos
- 🎬 Save Videos
- 🎥 Save Video Messages (Round)
- 🎤 Save Voice Messages
- 🎞 Save GIFs
- 🖼 Save Stickers
- 📎 Save Documents
- 📝 Save Text Messages
- ⌨️ Custom save commands (add/remove via Telegram)
- 💾 Database tracking
- 📊 Statistics
- 🔄 Auto-restart with systemd
- 🚀 No files stored on server (deleted after sending)

## 📋 Requirements

- Python 3.8+
- Telegram API credentials from [my.telegram.org](https://my.telegram.org)
- Ubuntu/Debian server (for 24/7 running)
